Jilo Studio 0.6.4. Apple silicon, macOS 15 Sequoia or later.

- Updates install from inside the app. Download and Install in the Software Update window shows the download's progress, checks the new version (its checksum and its Apple Developer ID signature), and Restart and Install puts it in place and opens it again — or Install When I Quit does it at the next quit. After the restart the app says the update is installed. If this copy can't replace itself (for example, it runs from the disk image), the window says why and opens the downloaded disk image, with the steps to install it by hand.
- The release notes in that window show menu paths properly (Settings › General instead of empty boxes).

To get this version from 0.6.3 or older, download it from this page once: from 0.6.4 on, updates install themselves.

## По-русски

Jilo Studio 0.6.4. Нужны Mac на Apple silicon и macOS 15 Sequoia или новее.

- Обновления устанавливаются прямо из приложения. «Скачать и установить» в окне «Обновление программы» показывает ход загрузки, проверяет новую версию (контрольную сумму и подпись Apple Developer ID), а «Перезапустить и установить» ставит её на место и открывает снова — или «Установить при выходе» сделает это при следующем закрытии. После перезапуска приложение сообщает, что обновление установлено. Если эта копия не может заменить себя сама (например, запущена прямо с образа диска), окно объясняет почему и открывает скачанный образ с шагами для ручной установки.
- Заметки о выпуске в этом окне правильно показывают пути в меню (Настройки › Общие вместо пустых квадратиков).

Чтобы перейти на эту версию с 0.6.3 или более ранней, один раз скачайте её с этой страницы: начиная с 0.6.4 обновления устанавливаются сами.
