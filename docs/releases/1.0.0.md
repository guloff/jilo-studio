Jilo Studio 1.0.0. Apple silicon, macOS 15 Sequoia or later. An AI-first video editor for the Mac, now a project of its own: its own project format, names and files throughout.

Projects and files:

- Projects are saved as `.jsproj` and graphics templates as `.jstpl`. Projects (`.fcproj`) and templates (`.fcgt`) from earlier versions open as before; a project opened from a `.fcproj` file is saved back to that file, and Save As offers `.jsproj`.
- Finder knows both kinds of project file; double-click either one to open it in Jilo Studio.
- Exchange files are written with Jilo Studio's own keys: OpenTimelineIO, FCPXML, Final Cut Pro 7 XML, AAF and OMF exports keep effects, generators and clip settings under the Jilo Studio name. Files exported by earlier versions import as before.
- Render previews live in a "Jilo Studio Previews" folder next to the project; the previews of an earlier version are moved there the first time the project opens.
- The log is `jilo-studio.log` (Help ▸ Reveal Log Files…); keyboard shortcuts, unsaved changes to recover and settings carry over from 0.12.

For scripts and assistants:

- The command-line tool is `jilo-cli` (it was `filmcraft-cli`); environment variables start with `JILO_` (`JILO_DATA_DIR`, `JILO_CONTROL_PORT`…), and the old `FILMCRAFT_` names still work.
- The MCP server introduces itself as `jilo-studio`, with resources at `jilo://document`, `jilo://commands`, `jilo://jobs` and `jilo://history`. An assistant connected with Settings ▸ AI ▸ Connect an Assistant keeps working; a configuration written by hand for `filmcraft-cli` needs the new path.

Also: Help ▸ Jilo Studio Help… opens Jilo Studio's own documentation, and the About window describes the app as an AI-first video editor. Jilo Studio began as a fork of FilmCraft by the ArtCraft team, credited in Help ▸ About Jilo Studio.

## По-русски

Jilo Studio 1.0.0. Нужны Mac на Apple silicon и macOS 15 Sequoia или новее. Видеоредактор для Mac с ИИ на первом месте — теперь самостоятельный проект: свой формат проектов, свои имена и файлы.

Проекты и файлы:

- Проекты сохраняются в `.jsproj`, шаблоны графики — в `.jstpl`. Проекты (`.fcproj`) и шаблоны (`.fcgt`) прежних версий открываются как раньше; проект, открытый из `.fcproj`, сохраняется в тот же файл, а «Сохранить как» предлагает `.jsproj`.
- Finder знает оба вида файлов проекта: двойной щелчок открывает любой из них в Jilo Studio.
- Файлы обмена пишутся со своими ключами Jilo Studio: при экспорте в OpenTimelineIO, FCPXML, XML Final Cut Pro 7, AAF и OMF эффекты, генераторы и настройки клипов сохраняются под именем Jilo Studio. Файлы, экспортированные прежними версиями, импортируются как раньше.
- Превью рендера лежат в папке «Jilo Studio Previews» рядом с проектом; превью прежней версии переносятся туда при первом открытии проекта.
- Журнал — `jilo-studio.log` («Справка ▸ Показать файлы журнала…»); сочетания клавиш, несохранённые изменения для восстановления и настройки переходят с 0.12.

Для скриптов и ассистентов:

- Утилита командной строки называется `jilo-cli` (была `filmcraft-cli`); переменные окружения начинаются с `JILO_` (`JILO_DATA_DIR`, `JILO_CONTROL_PORT`…), старые `FILMCRAFT_` тоже работают.
- MCP-сервер представляется как `jilo-studio`, ресурсы — `jilo://document`, `jilo://commands`, `jilo://jobs` и `jilo://history`. Ассистент, подключённый в «Настройки ▸ AI ▸ Подключить ассистента», работает дальше; конфигурацию, написанную вручную для `filmcraft-cli`, нужно перевести на новый путь.

Ещё: «Справка ▸ Справка Jilo Studio…» открывает собственную документацию Jilo Studio, а окно «О программе» описывает приложение как видеоредактор с ИИ на первом месте. Jilo Studio начинался как форк FilmCraft от команды ArtCraft — об этом сказано в «Справка ▸ О программе Jilo Studio».
